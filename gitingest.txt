# Traditional Filipino Dama Ruleset & Engine Specification

Use this reference whenever working on `src/engines/damaEngine.ts` or the Filipino Dama board UI.

## 1. Board Geometry & Initial Setup

- **Grid:** `8 × 8` board (`row: 0..7`, `col: 0..7`).
- **Playable Squares:** Only squares where `(row + col) % 2 === 1` (the 32 dark/diagonal-intersection squares) are playable.
- **Traditional Diagonal Lines:** Filipino Dama boards feature explicit diagonal guide lines connecting all playable squares along the `NE–SW` and `NW–SE` axes.
- **Starting Pieces (`12` per player):**
  - **Player 1 (Bottom, `"p1"`):** Occupies playable squares on rows `5, 6, 7`. Moves forward toward row `0` (`dRow = -1`).
  - **Player 2 (Top, `"p2"`):** Occupies playable squares on rows `0, 1, 2`. Moves forward toward row `7` (`dRow = +1`).
  - Rows `3` and `4` start empty.

## 2. Piece Types

1. **`"tao"` (Normal Cat Piece):**
   - **Non-Capturing Move:** Steps `1` square diagonally **forward only** (`dRow = -1` for P1, `dRow = +1` for P2) to an adjacent empty playable square.
   - **Capturing Move (*Kain*):** Can jump over an adjacent opponent piece to an immediately empty square directly beyond it (`2` squares away diagonally) in **ANY of the 4 diagonal directions (both forward AND backward)**.
   - **Multi-Jump Chain:** If after landing from a capture, another capture is available from the new square (forward or backward), the *Tao* MUST continue jumping in the same turn.

2. **`"dama"` (Flying Cat King — Crown & Cape):**
   - **Non-Capturing Move:** Slides any number of unobstructed diagonal squares **forward or backward** along any of the 4 diagonal rays.
   - **Flying Capture:** Can jump over a single opponent piece located at any distance along an unobstructed diagonal ray (forward or backward) and land on **any empty square beyond** that opponent piece along the same ray (until blocked by another piece or the board edge).
   - **Multi-Jump Chain:** If landing on a particular square beyond the captured piece enables a subsequent capture along any diagonal ray (including 90-degree turns), the *Dama* must continue capturing.

## 3. Mandatory Maximum Capture (*Mayor* Rule)

1. **Capture is Mandatory:** If any legal capture exists on the board for the active player, non-capturing moves are illegal.
2. **Maximum Capture Count (*Mayor*):**
   - Among all possible legal capture sequences across all of the player's pieces, the player **MUST** choose a capture sequence that captures the **maximum possible number of opponent pieces** (`maxCapturedCount`).
   - Example: If Piece A can capture `1` piece, and Piece B can capture `2` pieces in a chain, ONLY Piece B's 2-piece capture sequence is legal.
   - When a *Dama* jumps an opponent piece and has multiple empty landing squares beyond it, if some landing squares allow continuing a multi-jump of length `N` while others stop at `N - 1`, the *Dama* **must** land on one of the squares that achieves the maximum total captures `N`.
3. **Captured Piece Removal Timing (Turkish Strike Rule):**
   - During a multi-jump sequence, jumped opponent pieces remain as obstacles on the board until the entire capture sequence finishes, and **cannot be jumped a second time** in the same turn. They are removed upon completion of the move sequence (or visually poofed as each jump completes while still blocking re-jumps).

## 4. Promotion to *Dama* (King)

- A `"tao"` promotes to `"dama"` **only when its turn ends** on the opponent's back rank (`row === 0` for P1, `row === 7` for P2).
- **Mid-Capture Pass-Through Rule:** If a `"tao"` reaches the back rank during a capture, and from that back-rank square it can immediately make another backward capture as a `"tao"`, it **must** continue capturing as a `"tao"` and does **not** promote to `"dama"` if it leaves the back rank before its turn ends.

## 5. Win & Draw Conditions

- A player wins when the opponent has `0` pieces remaining or has `0` legal moves on their turn.

# Supabase Couple Sync Skill

## 1. Dual-Channel Synchronization Pattern

1. **Realtime Broadcast (`< 50ms`, Ephemeral):**
   - Channel name: `room:${roomCode}`
   - Events:
     - `reaction`: Floating emoji or quick chat bubble (`{ id, sender, content, kind }`)
     - `dice_shake`: Live dice box shake preview before roll completes
     - `move_step`: Immediate optimistic move broadcast alongside DB upsert
2. **Realtime Presence:**
   - Tracks `{ slot: 'p1' | 'p2', onlineAt }` so both phones display a live green online indicator when the partner is connected.
3. **PostgreSQL Authoritative Persistence (`supabase/schema.sql`):**
   - `couple_rooms`: Stores `p1_avatar`, `p2_avatar`, lifetime win counters (`p1_dama_wins`, `p2_dama_wins`, `p1_snakes_wins`, `p2_snakes_wins`), and `current_mode`.
   - `active_matches`: Stores authoritative `state_json`, `turn`, and `board_seed`. When either phone wakes from sleep or reconnects to mobile data, it fetches `active_matches` to restore the exact board state.
   - `match_history`: Logs finished games for the Couple Scoreboard modal.

const CACHE_NAME = 'lovey-cat-arcade-v1';
const ASSETS = ['/', '/index.html', '/manifest.json', '/cat-icon.svg'];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(ASSETS))
  );
  self.skipWaiting();
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(
        keys.map((k) => (k !== CACHE_NAME ? caches.delete(k) : Promise.resolve()))
      )
    )
  );
  self.clients.claim();
});

self.addEventListener('fetch', (event) => {
  if (event.request.method !== 'GET') return;
  const url = new URL(event.request.url);
  if (url.origin !== self.location.origin) return;

  event.respondWith(
    fetch(event.request)
      .then((res) => {
        const copy = res.clone();
        caches.open(CACHE_NAME).then((cache) => cache.put(event.request, copy));
        return res;
      })
      .catch(() => caches.match(event.request))
  );
});

export function DamaBoardView({
  gameState,
  mySlot,
  p1Avatar,
  p2Avatar,
  passAndPlay,
  onCommitState,
  onResetMatch,
}: DamaBoardViewProps) {
  const [selectedPos, setSelectedPos] = useState<BoardPos | null>(null);
  const [poofEffect, setPoofEffect] = useState<PoofEffect | null>(null);

  const canControlCurrentTurn = passAndPlay || gameState.turn === mySlot;

  const legalSteps = useMemo(
    () => getLegalStepsForState(gameState),
    [gameState]
  );

  const mandatoryOrigins = useMemo(
    () => getMandatoryCaptureOrigins(gameState),
    [gameState]
  );

  useEffect(() => {
    if (gameState.chainPos) {
      setSelectedPos(gameState.chainPos);
    } else {
      setSelectedPos(null);
    }
  }, [gameState.chainPos, gameState.turn]);

  useEffect(() => {
    if (!gameState.lastAction) return;
    const cap: CapturedPieceInfo | null = gameState.lastAction.captured ?? null;
    if (gameState.winner) {
      playVictoryFanfare();
    } else if (cap) {
      playCatPounceCapture();
    } else {
      playCatStep();
    }
    if (!cap) return;
    const effectId = gameState.lastAction.id;
    setPoofEffect({
      id: effectId,
      r: cap.r,
      c: cap.c,
      victimOwner: cap.piece.owner,
    });
    const timer = window.setTimeout(() => {
      setPoofEffect((prev) => (prev?.id === effectId ? null : prev));
    }, 680);
    return () => clearTimeout(timer);
  }, [gameState.lastAction?.id, gameState.winner]);

  const stepsForSelected = useMemo(() => {
    if (!selectedPos) return [];
    return legalSteps.filter((s) => samePos(s.from, selectedPos));
  }, [legalSteps, selectedPos]);

  const handleSquareTap = (r: number, c: number) => {
    if (gameState.winner || !canControlCurrentTurn) return;

    const tappedPos: BoardPos = { r, c };

    const matchingStep = stepsForSelected.find((s) => samePos(s.to, tappedPos));
    if (selectedPos && matchingStep) {
      const nextState = applyDamaStep(gameState, selectedPos, tappedPos);
      onCommitState(nextState);
      return;
    }

    if (gameState.chainPos) {
      setSelectedPos(gameState.chainPos);
      return;
    }

    const cellPiece = gameState.board[r][c];
    if (cellPiece && cellPiece.owner === gameState.turn) {
      const hasMoves = legalSteps.some((s) => samePos(s.from, tappedPos));
      if (hasMoves) {
        playTapPop();
        setSelectedPos(tappedPos);
      } else if (mandatoryOrigins.size > 0) {
        const firstKey = Array.from(mandatoryOrigins)[0];
        if (firstKey) {
          playTapPop();
          const [mr, mc] = firstKey.split(',').map(Number);
          setSelectedPos({ r: mr, c: mc });
        }
      }
    } else {
      setSelectedPos(null);
    }
  };

  const hasMandatoryCapture = mandatoryOrigins.size > 0;
  const ghostCapturedSet = new Set(gameState.capturedInChain);

  return (
    <div className="dama-stage-container">
      {hasMandatoryCapture && !gameState.winner && (
        <div className="mayor-floating-alert">
          <SparkleIcon size={14} />
          <span>Mandatory Capture! Jump with the glowing cat</span>
        </div>
      )}

      {/* Cohesive Sticker-Cartoony 8x8 Dama Board with Plum Outline */}
      <div className="board-stage sticker-board-frame">
        <svg
          viewBox="0 0 100 100"
          className="board-svg"
          role="grid"
          aria-label="Cat Dama 8x8 Board"
        >
          {/* Warm Cream Base */}
          <rect x="0" y="0" width="100" height="100" fill="#FFF8F2" />

          {/* 64 Connected Checkerboard Squares (Deeper Pink Playable + Cream Non-Playable) */}
          {Array.from({ length: 8 }).map((_, r) =>
            Array.from({ length: 8 }).map((__, c) => {
              const playable = isPlayableSquare(r, c);
              const isSelected = samePos(selectedPos, { r, c });
              const isTarget = stepsForSelected.some((s) =>
                samePos(s.to, { r, c })
              );
              const isLastFrom = samePos(gameState.lastAction?.from ?? null, {
                r,
                c,
              });
              const isLastTo = samePos(gameState.lastAction?.to ?? null, {
                r,
                c,
              });

              let squareFill = playable ? '#FF9EBB' : '#FFF8F2';
              if (isSelected) squareFill = '#BFF0D8';
              else if (isTarget) squareFill = '#FFE08A';
              else if (isLastFrom || isLastTo) squareFill = '#FFC2D4';

              return (
                <rect
                  key={`sq-${r}-${c}`}
                  x={c * 12.5}
                  y={r * 12.5}
                  width="12.5"
                  height="12.5"
                  fill={squareFill}
                  stroke="rgba(91, 42, 78, 0.12)"
                  stroke-width="0.25"
                  onClick={() => playable && handleSquareTap(r, c)}
                  style={{ cursor: playable ? 'pointer' : 'default' }}
                />
              );
            })
          )}

          {/* Pulsing Paw Print Move Hints */}
          {stepsForSelected.map((step) => {
            const cx = step.to.c * 12.5 + 6.25;
            const cy = step.to.r * 12.5 + 6.25;
            const isCaptureTarget = Boolean(step.captured);
            return (
              <g
                key={`target-${step.to.r}-${step.to.c}`}
                transform={`translate(${cx}, ${cy})`}
                onClick={() => handleSquareTap(step.to.r, step.to.c)}
                style={{ cursor: 'pointer' }}
              >
                <PawTargetHintSvg isCapture={isCaptureTarget} />
              </g>
            );
          })}

          {/* Render All Cat Pieces on the Board */}
          {gameState.board.map((row, r) =>
            row.map((piece, c) => {
              if (!piece) return null;
              const cx = c * 12.5 + 6.25;
              const cy = r * 12.5 + 6.25;
              const key = posKey(r, c);
              const isSelected = samePos(selectedPos, { r, c });
              const isMandatory = mandatoryOrigins.has(key);
              const isJustMoved = samePos(gameState.lastAction?.to ?? null, {
                r,
                c,
              });
              const isGhostCaptured = ghostCapturedSet.has(key);

              return (
                <g
                  key={piece.id}
                  transform={`translate(${cx}, ${cy})`}
                  onClick={() => handleSquareTap(r, c)}
                  style={{
                    cursor: canControlCurrentTurn ? 'pointer' : 'default',
                  }}
                >
                  <DamaCatToken
                    piece={piece}
                    avatar={piece.owner === 'p1' ? p1Avatar : p2Avatar}
                    isSelected={isSelected}
                    isMandatory={isMandatory}
                    isJustMoved={isJustMoved}
                    isGhostCaptured={isGhostCaptured}
                  />
                </g>
              );
            })
          )}

          {/* Capture Puff of Stars + NYOOM! */}
          {poofEffect && <PawSmackPoofSvg r={poofEffect.r} c={poofEffect.c} />}
        </svg>
      </div>

      {/* Victory Celebration Sticker Card */}
      {gameState.winner && (
        <div className="victory-overlay-card">
          <CoupleCatsSceneSvg
            p1Breed={p1Avatar.breed}
            p2Breed={p2Avatar.breed}
            showTrophy
            size={140}

const SNAKE_PALETTE = [
  '#6BCB77',
  '#4FC3C9',
  '#A78BFA',
  '#FF8A80',
  '#FFD166',
  '#74B9FF',
] as const;

function snakePath(
  a: { x: number; y: number },
  b: { x: number; y: number },
  amp: number,
  waves = 3,
  n = 32
): string {
  const dx = b.x - a.x;
  const dy = b.y - a.y;
  const len = Math.hypot(dx, dy) || 1;
  const nx = -dy / len;
  const ny = dx / len;
  let d = '';
  for (let i = 0; i <= n; i++) {
    const t = i / n;
    const off =
      Math.sin(t * Math.PI * 2 * waves) * amp * Math.min(1, t * 4, (1 - t) * 4);
    d +=
      (i ? ' L' : 'M') +
      (a.x + dx * t + nx * off).toFixed(1) +
      ' ' +
      (a.y + dy * t + ny * off).toFixed(1);
  }
  return d;
}

/**
 * Honey-Wood Ladder with Plum (#5B2A4E) Outlines & Rungs
 */
function WoodenLadderSvg({ link }: { link: BoardJumpLink }) {
  const start = tileToSvgCenter(link.from);
  const end = tileToSvgCenter(link.to);
  const dx = end.x - start.x;
  const dy = end.y - start.y;
  const len = Math.hypot(dx, dy) || 1;
  const nx = (-dy / len) * 1.75;
  const ny = (dx / len) * 1.75;

  const rungsCount = Math.max(3, Math.floor(len / 5.2));
  const rungs = [];
  for (let i = 1; i < rungsCount; i++) {
    const t = i / rungsCount;
    const cx = start.x + dx * t;
    const cy = start.y + dy * t;
    rungs.push(
      <g key={i}>
        <line
          x1={cx - nx}
          y1={cy - ny}
          x2={cx + nx}
          y2={cy + ny}
          stroke="#5B2A4E"
          stroke-width="1.35"
          stroke-linecap="round"
        />
        <line
          x1={cx - nx}
          y1={cy - ny}
          x2={cx + nx}
          y2={cy + ny}
          stroke="#FBBF24"
          stroke-width="0.7"
          stroke-linecap="round"
        />
      </g>
    );
  }

  return (
    <g pointerEvents="none">
      <line
        x1={start.x - nx}
        y1={start.y - ny}
        x2={end.x - nx}
        y2={end.y - ny}
        stroke="#5B2A4E"
        stroke-width="1.65"
        stroke-linecap="round"
      />
      <line
        x1={start.x + nx}
        y1={start.y + ny}
        x2={end.x + nx}
        y2={end.y + ny}
        stroke="#5B2A4E"
        stroke-width="1.65"
        stroke-linecap="round"
      />
      {rungs}
      <line
        x1={start.x - nx}
        y1={start.y - ny}
        x2={end.x - nx}
        y2={end.y - ny}
        stroke="#F59E0B"
        stroke-width="0.9"
        stroke-linecap="round"
      />
      <line
        x1={start.x + nx}
        y1={start.y + ny}
        x2={end.x + nx}
        y2={end.y + ny}
        stroke="#F59E0B"
        stroke-width="0.9"
        stroke-linecap="round"
      />
    </g>
  );
}

/**
 * Wavy Cartoon Snake with 3 Stacked Strokes, Saturated Body Color, Oval Head, Big White Eyes & Forked Tongue
 */
function CartoonSnakeSvg({
  link,
  index,
}: {
  link: BoardJumpLink;
  index: number;
}) {
  const head = tileToSvgCenter(link.from);
  const tail = tileToSvgCenter(link.to);
  const bodyColor = SNAKE_PALETTE[index % SNAKE_PALETTE.length];
  const amp = 3.0; // ~0.3 tile in 100x100 viewBox
  const waves = 3;
  const pathD = snakePath(head, tail, amp, waves, 32);

  // First segment direction from head -> p1, then +180deg so head faces away from body
  const dx = tail.x - head.x;
  const dy = tail.y - head.y;
  const len = Math.hypot(dx, dy) || 1;
  const nx = -dy / len;
  const ny = dx / len;
  const t1 = 1 / 32;
  const off1 =
    Math.sin(t1 * Math.PI * 2 * waves) * amp * Math.min(1, t1 * 4, (1 - t1) * 4);
  const segDx = dx * t1 + nx * off1;
  const segDy = dy * t1 + ny * off1;
  const headAngleDeg = (Math.atan2(-segDy, -segDx) * 180) / Math.PI;

  return (
    <g pointerEvents="none">
      {/* Tapered Tail Tip (~0.12 tile) */}
      <circle
        cx={tail.x}
        cy={tail.y}
        r="0.95"

  const [displayP2Tile, setDisplayP2Tile] = useState(gameState.p2Tile);

    () => new Set(generatedBoard.ladders.map((l) => l.from)),
    [generatedBoard.ladders]
  );
  const snakeHeadSet = useMemo(
    () => new Set(generatedBoard.snakes.map((s) => s.from)),
    [generatedBoard.snakes]
  );

  useEffect(() => {
    if (gameState.lastAnimation?.dice) {
      setPreviewDice(gameState.lastAnimation.dice);

      setDisplayP2Tile(gameState.p2Tile);
      return;

      anim.roller === 'p1' ? setDisplayP1Tile : setDisplayP2Tile;

            : anim.startTile - step;
        playCatStep();
        setRollerTile(nextTile);
      }, step * stepMs);

            const twist = generatedBoard.twists.find((t) => t.tile === tileNum);

            let tileFill = isEven ? '#FFF8F2' : '#FFD6E4';
            if (tileNum === 100) tileFill = '#FFE08A';

import { PlayerSlot } from '../types/arcade';

export type DamaPieceKind = 'tao' | 'dama';

export interface DamaPiece {
  id: string;

  kind: DamaPieceKind;
}

  r: number;
  c: number;
}

export interface CapturedPieceInfo {
  r: number;

}

export interface DamaStepOption {
  from: BoardPos;
  to: BoardPos;

export interface DamaGameState {
  board: (DamaPiece | null)[][];

  p2Remaining: number;

const DIAGONALS: readonly [number, number][] = [
  [-1, -1],
  [-1, 1],
  [1, -1],
  [1, 1],
];

export function isInsideBoard(r: number, c: number): boolean {
  return r >= 0 && r < 8 && c >= 0 && c < 8;
}

export function isPlayableSquare(r: number, c: number): boolean {
  return isInsideBoard(r, c) && (r + c) % 2 === 1;
}

export function posKey(r: number, c: number): string {
  return `${r},${c}`;
}

export function samePos(a: BoardPos | null, b: BoardPos | null): boolean {
  return Boolean(a && b && a.r === b.r && a.c === b.c);
}

export function cloneBoard(
  board: (DamaPiece | null)[][]
): (DamaPiece | null)[][] {
  return board.map((row) => row.map((cell) => (cell ? { ...cell } : null)));
}

export function createInitialDamaState(): DamaGameState {
  const board: (DamaPiece | null)[][] = Array.from({ length: 8 }, () =>
    Array<DamaPiece | null>(8).fill(null)
  );

  let p2Count = 0;
  for (let r = 0; r <= 2; r++) {
    for (let c = 0; c < 8; c++) {
      if (isPlayableSquare(r, c)) {
        p2Count += 1;
        board[r][c] = {
          id: `p2-${p2Count}`,
          owner: 'p2',
          kind: 'tao',
        };
      }
    }
  }

  let p1Count = 0;
  for (let r = 5; r <= 7; r++) {
    for (let c = 0; c < 8; c++) {
      if (isPlayableSquare(r, c)) {
        p1Count += 1;
        board[r][c] = {
          id: `p1-${p1Count}`,
          owner: 'p1',
          kind: 'tao',
        };
      }
    }
  }

  return {
    board,
    turn: 'p1',
    chainPos: null,
    capturedInChain: [],
    winner: null,
    p1Remaining: 12,
    p2Remaining: 12,
    lastAction: null,
  };
}

function isPromotionRow(owner: PlayerSlot, r: number): boolean {
  return (owner === 'p1' && r === 0) || (owner === 'p2' && r === 7);
}

interface ImmediateCapture {
  from: BoardPos;
  to: BoardPos;
  captured: CapturedPieceInfo;
}

/**
 * Finds all immediate 1-jump captures for a single piece at `pos`,
 * respecting already-captured ghost obstacles during a multi-jump chain
 * (Turkish strike rule: jumped pieces cannot be jumped twice).
 */
function getImmediateCapturesForPiece(
  board: (DamaPiece | null)[][],
  pos: BoardPos,
  piece: DamaPiece,
  alreadyCaptured: Set<string>
): ImmediateCapture[] {
  const results: ImmediateCapture[] = [];

  if (piece.kind === 'tao') {
    // Filipino Dama: Tao captures both forward AND backward diagonally (short jump)
    for (const [dr, dc] of DIAGONALS) {
      const midR = pos.r + dr;
      const midC = pos.c + dc;
      const landR = pos.r + dr * 2;
      const landC = pos.c + dc * 2;

      if (!isInsideBoard(landR, landC)) continue;
      const midKey = posKey(midR, midC);
      if (alreadyCaptured.has(midKey)) continue;

      const midPiece = board[midR][midC];
      const landPiece = board[landR][landC];

      if (midPiece && midPiece.owner !== piece.owner && landPiece === null) {
        results.push({
          from: pos,
          to: { r: landR, c: landC },
          captured: { r: midR, c: midC, piece: midPiece },
        });
      }
    }
  } else {
    // Flying King (Dama): Slides any distance to jump a single opponent piece,
    // and can land on ANY unobstructed empty square beyond that piece along the ray.
    for (const [dr, dc] of DIAGONALS) {
      let step = 1;
      let foundEnemy: CapturedPieceInfo | null = null;

      while (true) {
        const curR = pos.r + dr * step;
        const curC = pos.c + dc * step;
        if (!isInsideBoard(curR, curC)) break;

        const curKey = posKey(curR, curC);
        const occupant = board[curR][curC];

        if (!foundEnemy) {
          if (alreadyCaptured.has(curKey)) {
            // Cannot jump over an already-captured piece a second time
            break;
          }
          if (occupant) {
            if (occupant.owner === piece.owner) {
              break; // Blocked by friendly piece
            } else {
              foundEnemy = { r: curR, c: curC, piece: occupant };
            }
          }
        } else {
          // Already jumped `foundEnemy`; any empty square beyond it is a valid landing
          if (occupant !== null || alreadyCaptured.has(curKey)) {
            break; // Blocked by another piece
          }
          results.push({
            from: pos,
            to: { r: curR, c: curC },
            captured: foundEnemy,
          });
        }

        step += 1;
      }
    }
  }

  return results;
}

/**
 * Recursively computes the maximum number of captures achievable starting from `pos`
 * with `piece`, given the set of already-jumped squares `alreadyCaptured`.
 */
function computeMaxCaptureDepth(
  board: (DamaPiece | null)[][],
  pos: BoardPos,
  piece: DamaPiece,
  alreadyCaptured: Set<string>
): number {
  const immediate = getImmediateCapturesForPiece(
    board,
    pos,
    piece,
    alreadyCaptured
  );
  if (immediate.length === 0) return 0;

  let best = 0;
  for (const cap of immediate) {
    const nextBoard = cloneBoard(board);
    nextBoard[pos.r][pos.c] = null;
    nextBoard[cap.to.r][cap.to.c] = piece;
    // Note: in Turkish strike, captured piece stays as a blocker in `alreadyCaptured`
    const nextCaptured = new Set(alreadyCaptured);
    nextCaptured.add(posKey(cap.captured.r, cap.captured.c));

    const total =
      1 + computeMaxCaptureDepth(nextBoard, cap.to, piece, nextCaptured);
    if (total > best) {
      best = total;
    }
  }
  return best;
}

/**
 * Computes all legal next steps for the active player, strictly enforcing the
 * Filipino Dama Mandatory Maximum Capture (Mayor) rule.
 */
export function getLegalStepsForState(state: DamaGameState): DamaStepOption[] {
  if (state.winner) return [];

  const { board, turn, chainPos, capturedInChain } = state;
  const alreadyCaptured = new Set<string>(capturedInChain);

  const candidatePositions: BoardPos[] = [];
  if (chainPos) {
    candidatePositions.push(chainPos);
  } else {
    for (let r = 0; r < 8; r++) {
      for (let c = 0; c < 8; c++) {
        const p = board[r][c];
        if (p && p.owner === turn) {
          candidatePositions.push({ r, c });
        }
      }
    }
  }

  // 1. Gather all capture steps and evaluate their maximum total chain length
  const captureSteps: DamaStepOption[] = [];
  let globalMaxChain = 0;

  for (const pos of candidatePositions) {
    const piece = board[pos.r][pos.c];
    if (!piece) continue;

    const immediate = getImmediateCapturesForPiece(
      board,
      pos,
      piece,
      alreadyCaptured
    );

    for (const cap of immediate) {
      const nextBoard = cloneBoard(board);
      nextBoard[pos.r][pos.c] = null;
      nextBoard[cap.to.r][cap.to.c] = piece;

      const nextCaptured = new Set(alreadyCaptured);
      nextCaptured.add(posKey(cap.captured.r, cap.captured.c));

      const remainingCaptures = computeMaxCaptureDepth(
        nextBoard,
        cap.to,
        piece,
        nextCaptured
      );
      const totalChain = 1 + remainingCaptures;

      if (totalChain > globalMaxChain) {
        globalMaxChain = totalChain;
      }

      const promotes =
        piece.kind === 'tao' &&
        remainingCaptures === 0 &&
        isPromotionRow(piece.owner, cap.to.r);

      captureSteps.push({
        from: pos,
        to: cap.to,
        captured: cap.captured,
        maxChainLength: totalChain,
        promotes,
      });
    }
  }

  // Mandatory Maximum Capture (Mayor): If any capture exists, filter to max chain length only!
  if (globalMaxChain > 0) {
    return captureSteps.filter((step) => step.maxChainLength === globalMaxChain);
  }

  // If we were in a multi-jump chain and no further captures exist, return empty
  if (chainPos) {
    return [];
  }

  // 2. Otherwise, gather regular non-capturing diagonal moves
  const normalSteps: DamaStepOption[] = [];
  const forwardDr = turn === 'p1' ? -1 : 1;

  for (const pos of candidatePositions) {
    const piece = board[pos.r][pos.c];
    if (!piece) continue;

    if (piece.kind === 'tao') {
      for (const dc of [-1, 1]) {
        const nr = pos.r + forwardDr;
        const nc = pos.c + dc;
        if (isInsideBoard(nr, nc) && board[nr][nc] === null) {
          normalSteps.push({
            from: pos,
            to: { r: nr, c: nc },
            captured: null,
            maxChainLength: 0,
            promotes: isPromotionRow(piece.owner, nr),
          });
        }
      }
    } else {
      // Flying Dama King: Slides any number of empty squares along all 4 diagonals
      for (const [dr, dc] of DIAGONALS) {
        let dist = 1;
        while (true) {
          const nr = pos.r + dr * dist;
          const nc = pos.c + dc * dist;
          if (!isInsideBoard(nr, nc) || board[nr][nc] !== null) break;
          normalSteps.push({
            from: pos,
            to: { r: nr, c: nc },
            captured: null,
            maxChainLength: 0,
            promotes: false,
          });
          dist += 1;
        }
      }
    }
  }

  return normalSteps;
}

/**
 * Returns the set of piece coordinates ("r,c") that have a mandatory capture (Mayor).
 */
export function getMandatoryCaptureOrigins(state: DamaGameState): Set<string> {
  const steps = getLegalStepsForState(state);
  const origins = new Set<string>();
  for (const s of steps) {
    if (s.captured) {
      origins.add(posKey(s.from.r, s.from.c));
    }
  }
  return origins;
}

/**
 * Applies a validated step (`from` -> `to`) to `state` and returns the new `DamaGameState`.
 */
export function applyDamaStep(
  state: DamaGameState,
  from: BoardPos,
  to: BoardPos
): DamaGameState {
  const legalSteps = getLegalStepsForState(state);
  const chosen = legalSteps.find(
    (s) => samePos(s.from, from) && samePos(s.to, to)
  );
  if (!chosen) {
    return state;
  }

  const nextBoard = cloneBoard(state.board);
  const movingPiece = nextBoard[from.r][from.c];
  if (!movingPiece) return state;

  nextBoard[from.r][from.c] = null;
  const updatedPiece: DamaPiece = { ...movingPiece };
  nextBoard[to.r][to.c] = updatedPiece;

  let nextCapturedInChain = [...state.capturedInChain];
  if (chosen.captured) {
    nextCapturedInChain.push(posKey(chosen.captured.r, chosen.captured.c));
  }

  // Check if this was a capture and if further captures are required in this chain
  if (chosen.captured && chosen.maxChainLength > 1) {
    const intermediateState: DamaGameState = {
      ...state,
      board: nextBoard,
      chainPos: to,
      capturedInChain: nextCapturedInChain,
      lastAction: {
        id: `${Date.now()}-${from.r}${from.c}-${to.r}${to.c}`,
        mover: state.turn,
        from,
        to,
        captured: chosen.captured,
        promoted: false,
      },
    };
    return intermediateState;
  }

  // Turn sequence ends: remove all captured pieces in chain from board
  for (const key of nextCapturedInChain) {
    const [cr, cc] = key.split(',').map(Number);
    if (isInsideBoard(cr, cc)) {
      nextBoard[cr][cc] = null;
    }
  }

  // Check for Dama King promotion at end of turn
  let promoted = false;
  if (
    updatedPiece.kind === 'tao' &&
    isPromotionRow(updatedPiece.owner, to.r)
  ) {
    updatedPiece.kind = 'dama';
    promoted = true;
  }

  // Count remaining pieces
  let p1Remaining = 0;
  let p2Remaining = 0;
  for (let r = 0; r < 8; r++) {
    for (let c = 0; c < 8; c++) {
      const cell = nextBoard[r][c];
      if (cell?.owner === 'p1') p1Remaining += 1;
      if (cell?.owner === 'p2') p2Remaining += 1;
    }
  }

  const nextTurn: PlayerSlot = state.turn === 'p1' ? 'p2' : 'p1';

  const provisionalNextState: DamaGameState = {
    board: nextBoard,
    turn: nextTurn,
    chainPos: null,
    capturedInChain: [],
    winner: null,
    p1Remaining,
    p2Remaining,
    lastAction: {
      id: `${Date.now()}-${from.r}${from.c}-${to.r}${to.c}`,
      mover: state.turn,
      from,
      to,
      captured: chosen.captured,
      promoted,
    },
  };

  // Determine if game has ended (0 pieces left or 0 legal moves for next player)
  if (p1Remaining === 0) {
    provisionalNextState.winner = 'p2';
  } else if (p2Remaining === 0) {
    provisionalNextState.winner = 'p1';
  } else {
    const nextPlayerMoves = getLegalStepsForState(provisionalNextState);
    if (nextPlayerMoves.length === 0) {
      provisionalNextState.winner = state.turn;
    }
  }

  return provisionalNextState;
}

/**
 * Deterministic 32-bit PRNG (Mulberry32).
 * Guarantees identical board layouts across both phones from a single integer seed.
 */
export function createMulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return function next(): number {
    a |= 0;
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

/**
 * Converts a tile number (1..100) into SVG center coordinates (x: 0..100, y: 0..100)
 * on a 10x10 Boustrophedon (zig-zag) grid where tile 1 is bottom-left and 100 is top-left.
 */
export function tileToSvgCenter(tile: number): {
  x: number;
  y: number;
  row: number;
  col: number;
} {
  const clamped = Math.max(1, Math.min(100, tile));
  const zeroBased = clamped - 1;
  const rowFromBottom = Math.floor(zeroBased / 10); // 0..9
  const colInRow = zeroBased % 10;
  const col = rowFromBottom % 2 === 0 ? colInRow : 9 - colInRow;
  const row = 9 - rowFromBottom; // 0 is top row, 9 is bottom row

  return {
    x: col * 10 + 5,
    y: row * 10 + 5,
    row,
    col,
  };
}

/**
 * Returns true if segment AB and segment CD intersect or pass within `minDist` of each other.
 */
function segmentsConflict(
  fromA: number,
  toA: number,
  fromB: number,
  toB: number
): boolean {
  const a1 = tileToSvgCenter(fromA);
  const a2 = tileToSvgCenter(toA);
  const b1 = tileToSvgCenter(fromB);
  const b2 = tileToSvgCenter(toB);

  const ccw = (
    p1: { x: number; y: number },
    p2: { x: number; y: number },
    p3: { x: number; y: number }
  ) => (p3.y - p1.y) * (p2.x - p1.x) > (p2.y - p1.y) * (p3.x - p1.x);

  const intersects =
    ccw(a1, b1, b2) !== ccw(a2, b1, b2) &&
    ccw(a1, a2, b1) !== ccw(a1, a2, b2);
  if (intersects) return true;

  // Also check midpoint proximity so wavy snakes and ladders don't visually crowd
  const midAx = (a1.x + a2.x) * 0.5;
  const midAy = (a1.y + a2.y) * 0.5;
  const midBx = (b1.x + b2.x) * 0.5;
  const midBy = (b1.y + b2.y) * 0.5;
  if (Math.hypot(midAx - midBx, midAy - midBy) < 13) return true;

  return false;
}

/**
 * Procedurally generates a clean, non-crossing Snakes & Ladders board from `seed`.
 * Uses 5 ladders and 5 snakes, each spanning <= 3 rows and <= 3 columns horizontally.
 */
export function generateSnakesBoard(
  seed: number,
  includeTwists = true
): GeneratedSnakesBoard {
  const rng = createMulberry32(seed);
  const usedEndpoints = new Set<number>([1, 100]);
  const startTiles = new Set<number>();

  const randInt = (min: number, max: number): number =>
    Math.floor(rng() * (max - min + 1)) + min;

  const createsThreeInARow = (tile: number): boolean => {
    return (
      (startTiles.has(tile - 1) && startTiles.has(tile - 2)) ||
      (startTiles.has(tile - 1) && startTiles.has(tile + 1)) ||
      (startTiles.has(tile + 1) && startTiles.has(tile + 2))
    );
  };

  const ladders: BoardJumpLink[] = [];
  const snakes: BoardJumpLink[] = [];
  const twists: TwistTile[] = [];
  const allLinks: { from: number; to: number }[] = [];

  const hasConflictWithExisting = (from: number, to: number): boolean => {
    for (const existing of allLinks) {
      if (segmentsConflict(from, to, existing.from, existing.to)) {
        return true;
      }
    }
    return false;
  };

  // 1. Generate 5 Non-Crossing Honey-Wood Ladders (each spanning 1..3 rows and <= 3 cols)
  const targetLadders = 5;
  let attempts = 0;
  while (ladders.length < targetLadders && attempts < 600) {
    attempts += 1;
    const from = randInt(3, 82);
    const fromCenter = tileToSvgCenter(from);
    const fromRowBottom = Math.floor((from - 1) / 10);
    const minToRow = fromRowBottom + 1;
    const maxToRow = Math.min(9, fromRowBottom + 3);
    if (minToRow > maxToRow) continue;

    const toRowBottom = randInt(minToRow, maxToRow);
    const to = toRowBottom * 10 + randInt(0, 9) + 1;
    const toCenter = tileToSvgCenter(to);

    if (to >= 99 || to <= from + 7) continue;
    if (Math.abs(toCenter.col - fromCenter.col) > 3) continue;
    if (usedEndpoints.has(from) || usedEndpoints.has(to)) continue;
    if (createsThreeInARow(from)) continue;
    if (hasConflictWithExisting(from, to)) continue;

    usedEndpoints.add(from);
    usedEndpoints.add(to);
    startTiles.add(from);
    allLinks.push({ from, to });

    ladders.push({
      id: `ladder-${ladders.length + 1}`,
      kind: 'ladder',
      from,
      to,
      color: '#F59E0B',
    });
  }

  // 2. Generate 5 Non-Crossing Chunky Cartoon Snakes (each spanning 1..3 rows and <= 3 cols)
  const targetSnakes = 5;
  attempts = 0;
  while (snakes.length < targetSnakes && attempts < 700) {
    attempts += 1;
    const hasHighSnake = snakes.some((s) => s.from >= 92);
    const maxFrom = hasHighSnake ? 91 : 98;
    const from = randInt(18, maxFrom);
    const fromCenter = tileToSvgCenter(from);
    const fromRowBottom = Math.floor((from - 1) / 10);
    if (fromRowBottom < 1) continue;

    const minToRow = Math.max(0, fromRowBottom - 3);
    const maxToRow = fromRowBottom - 1;
    const toRowBottom = randInt(minToRow, maxToRow);
    const to = toRowBottom * 10 + randInt(0, 9) + 1;
    const toCenter = tileToSvgCenter(to);

    if (to <= 2 || from <= to + 7) continue;
    if (Math.abs(toCenter.col - fromCenter.col) > 3) continue;
    if (usedEndpoints.has(from) || usedEndpoints.has(to)) continue;
    if (createsThreeInARow(from)) continue;
    if (hasConflictWithExisting(from, to)) continue;

    usedEndpoints.add(from);
    usedEndpoints.add(to);
    startTiles.add(from);
    allLinks.push({ from, to });

    snakes.push({
      id: `snake-${snakes.length + 1}`,
      kind: 'snake',
      from,
      to,
      color: SNAKE_COLORS[snakes.length % SNAKE_COLORS.length],
    });
  }

  // 3. Generate 4 Mystery Twist Tiles (if enabled)
  if (includeTwists) {
    const twistSpecs: readonly {
      kind: TwistKind;
      label: string;
      icon: string;
    }[] = [
      { kind: 'boost', label: 'Catnip Boost +3!', icon: '+3' },
      { kind: 'shield', label: 'Snake Shield!', icon: 'SHIELD' },
      { kind: 'extra_roll', label: 'Lucky Paw Extra Roll!', icon: 'ROLL' },
      { kind: 'swap', label: 'Switcheroo Swap!', icon: 'SWAP' },
    ];

    for (const spec of twistSpecs) {
      for (let tries = 0; tries < 80; tries++) {
        const tile = randInt(12, 88);
        if (usedEndpoints.has(tile) || createsThreeInARow(tile)) continue;
        usedEndpoints.add(tile);
        startTiles.add(tile);
        twists.push({
          tile,
          kind: spec.kind,
          label: spec.label,
          icon: spec.icon,
        });
        break;
      }
    }
  }

  return {
    seed,
    ladders,
    snakes,
    twists,
  };
}

/**
 * Pure turn resolver for Snakes & Ladders.
 */
export function applySnakesDiceRoll(
  state: SnakesGameState,
  dice: number
): SnakesGameState {
  if (state.winner) return state;

  const board = generateSnakesBoard(state.boardSeed, state.twistsEnabled);
  const roller = state.turn;
  const startTile = roller === 'p1' ? state.p1Tile : state.p2Tile;
  const otherTile = roller === 'p1' ? state.p2Tile : state.p1Tile;
  let hasShield = roller === 'p1' ? state.p1Shield : state.p2Shield;

  let walkLandingTile = startTile + dice;
  if (walkLandingTile > 100) {
    walkLandingTile = 100 - (walkLandingTile - 100);
  }

  let finalTile = walkLandingTile;
  let nextOtherTile = otherTile;
  let eventKind: SnakesTurnAnimation['eventKind'] = 'normal';
  let eventMessage = `Rolled ${dice} → Tile ${walkLandingTile}`;
  let grantExtraRoll = dice === 6;

  const ladder = board.ladders.find((l) => l.from === walkLandingTile);
  const snake = board.snakes.find((s) => s.from === walkLandingTile);
  const twist = board.twists.find((t) => t.tile === walkLandingTile);

  if (ladder) {
    finalTile = ladder.to;
    eventKind = 'ladder';
    eventMessage = `Climbed Ladder ${ladder.from} → ${ladder.to}!`;
  } else if (snake) {
    if (hasShield) {
      hasShield = false;
      finalTile = walkLandingTile;
      eventKind = 'shield_saved';
      eventMessage = `Shield blocked Snake at ${snake.from}!`;
    } else {
      finalTile = snake.to;
      eventKind = 'snake';
      eventMessage = `Oh no! Slid down Snake ${snake.from} → ${snake.to}!`;
    }
  } else if (twist) {
    if (twist.kind === 'boost') {
      finalTile = Math.min(100, walkLandingTile + 3);
      eventKind = 'boost';
      eventMessage = `Catnip Boost! Jumped +3 → Tile ${finalTile}!`;
    } else if (twist.kind === 'shield') {
      hasShield = true;
      eventKind = 'shield_gain';
      eventMessage = `Picked up a Snake Shield!`;
    } else if (twist.kind === 'extra_roll') {
      grantExtraRoll = true;
      eventKind = 'extra_roll';
      eventMessage = `Lucky Paw! Earned an Extra Roll!`;
    } else if (twist.kind === 'swap') {
      if (otherTile !== walkLandingTile && otherTile > 1 && otherTile < 100) {
        finalTile = otherTile;
        nextOtherTile = walkLandingTile;
        eventKind = 'swap';
        eventMessage = `Switcheroo! Swapped tiles ${walkLandingTile} ↔ ${otherTile}!`;
      } else {
        finalTile = Math.min(100, walkLandingTile + 2);
        eventKind = 'boost';
        eventMessage = `Mystery Hop +2 → Tile ${finalTile}!`;
      }
    }
  }

  const nextP1Tile = roller === 'p1' ? finalTile : nextOtherTile;
  const nextP2Tile = roller === 'p2' ? finalTile : nextOtherTile;
  const nextP1Shield = roller === 'p1' ? hasShield : state.p1Shield;
  const nextP2Shield = roller === 'p2' ? hasShield : state.p2Shield;

  const winner: PlayerSlot | null =
    nextP1Tile === 100 ? 'p1' : nextP2Tile === 100 ? 'p2' : null;

  const nextTurn: PlayerSlot =
    winner || !grantExtraRoll ? (roller === 'p1' ? 'p2' : 'p1') : roller;

  if (!winner && dice === 6 && eventKind === 'normal') {
    eventMessage = `Rolled a 6! Tile ${finalTile} + Bonus Roll!`;
  }

  return {
    boardSeed: state.boardSeed,
    twistsEnabled: state.twistsEnabled,
    p1Tile: nextP1Tile,
    p2Tile: nextP2Tile,
    p1Shield: nextP1Shield,
    p2Shield: nextP2Shield,
    turn: nextTurn,
    winner,
    lastAnimation: {
      id: `${Date.now()}-${roller}-${dice}-${finalTile}`,
      roller,
      dice,
      startTile,
      walkLandingTile,
      finalTile,
      eventKind,
      eventMessage,
    },
  };
}

function playTone(
  freqStart: number,
  freqEnd: number,
  durationSec: number,
  type: OscillatorType = 'sine',
  gainPeak = 0.12,
  delaySec = 0
): void {
  const ctx = getAudioContext();
  if (!ctx) return;

  try {
    const startTime = ctx.currentTime + delaySec;
    const endTime = startTime + durationSec;

    const osc = ctx.createOscillator();
    const gain = ctx.createGain();

    osc.type = type;
    osc.frequency.setValueAtTime(freqStart, startTime);
    if (freqEnd !== freqStart) {
      osc.frequency.exponentialRampToValueAtTime(
        Math.max(40, freqEnd),
        endTime
      );
    }

    gain.gain.setValueAtTime(0.001, startTime);
    gain.gain.linearRampToValueAtTime(gainPeak, startTime + durationSec * 0.18);
    gain.gain.exponentialRampToValueAtTime(0.001, endTime);

    osc.connect(gain);
    gain.connect(ctx.destination);

    osc.start(startTime);
    osc.stop(endTime + 0.01);
  } catch {
    // Ignore audio context errors on restricted devices
  }
}

export type RealtimeBroadcastEvent =
  | { type: 'reaction'; reaction: FloatingReaction }
  | { type: 'avatar_update'; slot: PlayerSlot; avatar: CatAvatarConfig }
  | { type: 'mode_switch'; mode: GameMode; sender: PlayerSlot }
  | { type: 'start_match'; mode: GameMode; sender: PlayerSlot }

export interface CoupleChannelHandlers {
  onBroadcast: (event: RealtimeBroadcastEvent) => void;
  onPartnerOnlineChange: (onlineSlots: Record<PlayerSlot, number>) => void;
  onResyncRequested: () => void;
  onConnectionChange?: (connected: boolean) => void;
}

export class CoupleRealtimeChannel {
  private ws: WebSocket | null = null;
  private roomCode: string;
  private slot: PlayerSlot;
  private handlers: CoupleChannelHandlers;
  private refCounter = 1;
  private joinRef = '1';
  private heartbeatTimer: number | null = null;
  private presencePingTimer: number | null = null;
  private reconnectTimer: number | null = null;
  private destroyed = false;
  private onlineSeen: Record<PlayerSlot, number> = { p1: 0, p2: 0 };

  constructor(
    roomCode: string,
    slot: PlayerSlot,
    handlers: CoupleChannelHandlers
  ) {
    this.roomCode = normalizeRoomCode(roomCode);
    this.slot = slot;
    this.handlers = handlers;
    this.onlineSeen[this.slot] = Date.now();
  }

  private get topic(): string {
    return `realtime:room:${this.roomCode}`;
  }

  private nextRef(): string {
    this.refCounter += 1;
    return String(this.refCounter);
  }

  public connect(): void {
    if (this.destroyed) return;
    this.cleanupSocket();

    try {
      const ws = new WebSocket(WS_URL);
      this.ws = ws;

      ws.onopen = () => {
        if (this.destroyed) return;
        this.handlers.onConnectionChange?.(true);
        this.joinRef = this.nextRef();

        // Join Phoenix Realtime Channel
        ws.send(
          JSON.stringify({
            topic: this.topic,
            event: 'phx_join',
            payload: {
              config: {
                broadcast: { ack: false, self: false },
                presence: { key: this.slot },
              },
            },
            ref: this.joinRef,
            join_ref: this.joinRef,
          })
        );

        // Immediately announce presence and start heartbeat
        this.sendBroadcast({
          type: 'presence_ping',
          slot: this.slot,
          timestamp: Date.now(),
        });

        this.heartbeatTimer = window.setInterval(() => {
          this.sendRaw('phoenix', 'heartbeat', {});
          this.pruneStalePresence();
        }, 20000);

        this.presencePingTimer = window.setInterval(() => {
          this.onlineSeen[this.slot] = Date.now();
          this.sendBroadcast({
            type: 'presence_ping',
            slot: this.slot,
            timestamp: Date.now(),
          });
          this.pruneStalePresence();
        }, 6000);
      };

      ws.onmessage = (evt) => {
        try {
          const msg = JSON.parse(String(evt.data)) as {
            topic?: string;
            event?: string;
            payload?: Record<string, unknown>;
          };
          if (msg.event === 'broadcast' && msg.payload) {
            const inner = msg.payload.payload as RealtimeBroadcastEvent | undefined;
            if (inner && typeof inner === 'object' && 'type' in inner) {
              if (inner.type === 'presence_ping') {
                const existedBefore =
                  Date.now() - (this.onlineSeen[inner.slot] || 0) < 16000;
                this.onlineSeen[inner.slot] = Date.now();
                this.handlers.onPartnerOnlineChange({ ...this.onlineSeen });
                if (!existedBefore && inner.slot !== this.slot) {
                  // Reply immediately so newly joined partner sees us right away
                  this.sendBroadcast({
                    type: 'presence_ping',
                    slot: this.slot,
                    timestamp: Date.now(),
                  });
                }
                return;
              }
              this.handlers.onBroadcast(inner);
            }
          }
        } catch {
          // Ignore malformed frames
        }
      };

      ws.onclose = () => {
        this.handlers.onConnectionChange?.(false);
        if (!this.destroyed) {
          this.reconnectTimer = window.setTimeout(() => {
            this.connect();
            this.handlers.onResyncRequested();
          }, 2200);
        }
      };

      ws.onerror = () => {
        ws.close();
      };
    } catch {
      this.handlers.onConnectionChange?.(false);
    }
  }

  public updateSlot(newSlot: PlayerSlot): void {
    this.slot = newSlot;
    this.onlineSeen[newSlot] = Date.now();
    this.sendBroadcast({
      type: 'presence_ping',
      slot: this.slot,
      timestamp: Date.now(),
    });
    this.handlers.onPartnerOnlineChange({ ...this.onlineSeen });
  }

  public sendBroadcast(eventPayload: RealtimeBroadcastEvent): void {
    if (!this.ws || this.ws.readyState !== WebSocket.OPEN) return;
    const ref = this.nextRef();
    this.ws.send(
      JSON.stringify({
        topic: this.topic,
        event: 'broadcast',
        payload: {
          type: 'broadcast',
          event: eventPayload.type,
          payload: eventPayload,
        },
        ref,
        join_ref: this.joinRef,
      })
    );
  }

  private sendRaw(topic: string, event: string, payload: Record<string, unknown>): void {
    if (!this.ws || this.ws.readyState !== WebSocket.OPEN) return;
    this.ws.send(
      JSON.stringify({
        topic,
        event,
        payload,
        ref: this.nextRef(),
      })
    );
  }

  private pruneStalePresence(): void {
    this.onlineSeen[this.slot] = Date.now();
    this.handlers.onPartnerOnlineChange({ ...this.onlineSeen });
  }

  private cleanupSocket(): void {
    if (this.heartbeatTimer !== null) {
      clearInterval(this.heartbeatTimer);
      this.heartbeatTimer = null;
    }
    if (this.presencePingTimer !== null) {
      clearInterval(this.presencePingTimer);
      this.presencePingTimer = null;
    }
    if (this.reconnectTimer !== null) {
      clearTimeout(this.reconnectTimer);
      this.reconnectTimer = null;
    }
    if (this.ws) {
      this.ws.onopen = null;
      this.ws.onmessage = null;
      this.ws.onclose = null;
      this.ws.onerror = null;
      try {
        this.ws.close();
      } catch {
        // Ignore
      }
      this.ws = null;
    }
  }

  public destroy(): void {
    this.destroyed = true;
    this.cleanupSocket();
  }
}

import { useCallback, useEffect, useRef, useState } from 'preact/hooks';
import {
  CatAvatarConfig,

  DEFAULT_P2_AVATAR,
  FloatingReaction,
  GameMode,
  PlayerSlot,
  QUICK_STICKERS,
  ReactionStickerId,

import { CatAvatarSvg } from './components/CatAvatarSvg';
import {
  CrownIcon,
  PawIcon,
  ReactionStickerSvg,
  SettingsGearIcon,
  SnakeLadderIcon,
  TrophyIcon,
} from './components/ArcadeIcons';
import { CatCustomizerModal } from './components/CatCustomizerModal';
import { CoupleScoreboardModal } from './components/CoupleScoreboardModal';
import { DamaTutorialModal } from './components/DamaTutorialModal';
import { HomeMenuView } from './components/HomeMenuView';
import { QuickChatBar } from './components/QuickChatBar';
import { DamaBoardView } from './components/DamaBoardView';

import {
  isSoundMuted,

const STORAGE_ROOM_KEY = 'lovey_arcade_room_code';
const STORAGE_SLOT_KEY = 'lovey_arcade_player_slot';
const STORAGE_TUTORIAL_PREFIX = 'lovey_seen_tutorial_';

const VALID_STICKER_IDS = new Set<string>(QUICK_STICKERS.map((s) => s.id));

export function App() {
  const [roomCode, setRoomCode] = useState<string>(() => {
    try {
      return normalizeRoomCode(
        localStorage.getItem(STORAGE_ROOM_KEY) || 'LOVEY'
      );
    } catch {
      return 'LOVEY';
    }
  });

  const [mySlot, setMySlot] = useState<PlayerSlot>(() => {
    try {
      const saved = localStorage.getItem(STORAGE_SLOT_KEY);
      return saved === 'p2' ? 'p2' : 'p1';
    } catch {
      return 'p1';
    }
  });

  const [roomData, setRoomData] = useState<CoupleRoomRow>({
    room_code: roomCode,
    p1_avatar: DEFAULT_P1_AVATAR,
    p2_avatar: DEFAULT_P2_AVATAR,
    p1_dama_wins: 0,
    p2_dama_wins: 0,
    p1_snakes_wins: 0,
    p2_snakes_wins: 0,
    current_mode: 'dama',
    updated_at: new Date().toISOString(),
  });

  const [activeScreen, setActiveScreen] = useState<'menu' | 'play'>('menu');
  const [damaState, setDamaState] = useState<DamaGameState>(() =>
    createInitialDamaState()
  );
  const [snakesState, setSnakesState] = useState<SnakesGameState>(() =>
    createInitialSnakesState(202610, true)
  );
  const [passAndPlay, setPassAndPlay] = useState<boolean>(false);
  const [reactions, setReactions] = useState<FloatingReaction[]>([]);
  const [onlineSeen, setOnlineSeen] = useState<Record<PlayerSlot, number>>({
    p1: Date.now(),
    p2: 0,
  });
  const [customizerOpen, setCustomizerOpen] = useState(false);
  const [scoreboardOpen, setScoreboardOpen] = useState(false);
  const [tutorialOpen, setTutorialOpen] = useState(false);
  const [muted, setMuted] = useState<boolean>(() => isSoundMuted());

  const channelRef = useRef<CoupleRealtimeChannel | null>(null);

  const checkAutoOpenTutorial = useCallback((mode: GameMode) => {
    try {
      const key = `${STORAGE_TUTORIAL_PREFIX}${mode}`;
      if (!localStorage.getItem(key)) {
        localStorage.setItem(key, '1');
        setTutorialOpen(true);
      }
    } catch {
      // Ignore storage errors
    }
  }, []);

  const spawnFloatingReaction = useCallback((reaction: FloatingReaction) => {
    playReactionChime();
    setReactions((prev) => [...prev.slice(-6), reaction]);
    window.setTimeout(() => {
      setReactions((prev) => prev.filter((item) => item.id !== reaction.id));
    }, 2150);
  }, []);

  const syncFromDatabase = useCallback(async (targetRoom: string) => {
    const [row, matchRow] = await Promise.all([
      fetchOrCreateCoupleRoom(targetRoom),
      fetchActiveMatch<unknown>(targetRoom),
    ]);
    setRoomData(row);
    if (matchRow && matchRow.state_json) {
      if (matchRow.game_mode === 'dama') {
        const maybeDama = matchRow.state_json as DamaGameState;
        if (Array.isArray(maybeDama.board)) {
          setDamaState(maybeDama);
        }
      } else if (matchRow.game_mode === 'snakes') {
        const maybeSnakes = matchRow.state_json as SnakesGameState;
        if (typeof maybeSnakes.boardSeed === 'number') {
          setSnakesState(maybeSnakes);
        }
      }
    }
  }, []);

  useEffect(() => {
    syncFromDatabase(roomCode);

    const channel = new CoupleRealtimeChannel(roomCode, mySlot, {
      onBroadcast: (event: RealtimeBroadcastEvent) => {
        if (event.type === 'reaction') {
          spawnFloatingReaction(event.reaction);
        } else if (event.type === 'avatar_update') {
          setRoomData((prev) =>
            event.slot === 'p1'
              ? { ...prev, p1_avatar: event.avatar }
              : { ...prev, p2_avatar: event.avatar }
          );
        } else if (event.type === 'partner_joined') {
          setOnlineSeen((prev) => ({ ...prev, [event.slot]: Date.now() }));
          setRoomData((prev) =>
            event.slot === 'p1'
              ? { ...prev, p1_avatar: event.avatar }
              : { ...prev, p2_avatar: event.avatar }
          );
        } else if (
          event.type === 'mode_switch' ||
          event.type === 'start_match'
        ) {
          setRoomData((prev) => ({ ...prev, current_mode: event.mode }));
          setActiveScreen('play');
          checkAutoOpenTutorial(event.mode);
        } else if (event.type === 'match_sync') {
          if (event.gameMode === 'dama') {
            const incoming = event.stateJson as DamaGameState;
            if (incoming && Array.isArray(incoming.board)) {
              setDamaState(incoming);
            }
          } else if (event.gameMode === 'snakes') {
            const incoming = event.stateJson as SnakesGameState;
            if (incoming && typeof incoming.boardSeed === 'number') {
              setSnakesState(incoming);
            }
          }
          if (event.winner) {
            fetchOrCreateCoupleRoom(roomCode).then(setRoomData);
          }
        }
      },
      onPartnerOnlineChange: (seenMap) => {
        setOnlineSeen(seenMap);
      },
      onResyncRequested: () => {
        syncFromDatabase(roomCode);
      },
    });

    channel.connect();
    channelRef.current = channel;

    const handleVisibilityOrOnline = () => {
      if (document.visibilityState === 'visible') {
        syncFromDatabase(roomCode);
      }
    };

    document.addEventListener('visibilitychange', handleVisibilityOrOnline);
    window.addEventListener('online', handleVisibilityOrOnline);

    return () => {
      document.removeEventListener(
        'visibilitychange',
        handleVisibilityOrOnline
      );
      window.removeEventListener('online', handleVisibilityOrOnline);
      channel.destroy();
      channelRef.current = null;
    };
  }, [
    roomCode,
    mySlot,
    spawnFloatingReaction,
    syncFromDatabase,
    checkAutoOpenTutorial,
  ]);

  const handleStartAsHost = async () => {
    playTapPop();
    setMySlot('p1');
    try {
      localStorage.setItem(STORAGE_SLOT_KEY, 'p1');
    } catch {
      // Ignore
    }
    channelRef.current?.updateSlot('p1');
    const row = await fetchOrCreateCoupleRoom(roomCode);
    setRoomData(row);
  };

  const handleAttemptJoinAsInvited = async (
    targetCode: string
  ): Promise<boolean> => {
    playTapPop();
    const cleaned = normalizeRoomCode(targetCode);
    const { ok, room } = await checkCoupleRoomExists(cleaned);
    if (!ok || !room) {
      return false;
    }

    setMySlot('p2');
    setRoomCode(cleaned);
    setRoomData(room);
    try {
      localStorage.setItem(STORAGE_ROOM_KEY, cleaned);
      localStorage.setItem(STORAGE_SLOT_KEY, 'p2');
    } catch {
      // Ignore
    }

    window.setTimeout(() => {
      channelRef.current?.updateSlot('p2');
      channelRef.current?.sendBroadcast({
        type: 'partner_joined',
        slot: 'p2',
        avatar: room.p2_avatar,
      });
    }, 380);

    return true;
  };

  const handleHostLaunchGame = (
    selectedMode: GameMode,
    soloPractice = false
  ) => {
    playTapPop();
    if (soloPractice) {
      setPassAndPlay(true);
    }
    setRoomData((prev) => ({ ...prev, current_mode: selectedMode }));
    setActiveScreen('play');
    checkAutoOpenTutorial(selectedMode);

    channelRef.current?.sendBroadcast({
      type: 'start_match',
      mode: selectedMode,
      sender: 'p1',
    });
    updateRoomModeInDb(roomCode, selectedMode);
  };

  const handleCommitDamaState = async (nextState: DamaGameState) => {
    setDamaState(nextState);

    channelRef.current?.sendBroadcast({
      type: 'match_sync',
      gameMode: 'dama',
      turn: nextState.turn,
      boardSeed: 0,
      stateJson: nextState,
      winner: nextState.winner,
      sender: mySlot,
    });

    await upsertActiveMatch({
      room_code: roomCode,
      game_mode: 'dama',
      turn: nextState.turn,
      board_seed: 0,
      state_json: nextState,
      winner: nextState.winner,
    });

    if (nextState.winner === 'p1' || nextState.winner === 'p2') {
      const updatedRoom = await recordMatchWinInDb(
        roomData,
        'dama',
        nextState.winner,
        `Cat Dama (${nextState.p1Remaining} - ${nextState.p2Remaining})`
      );
      if (updatedRoom) {
        setRoomData(updatedRoom);
      }
    }
  };

  const handleResetDamaMatch = async () => {
    const fresh = createInitialDamaState();
    setDamaState(fresh);
    channelRef.current?.sendBroadcast({
      type: 'match_sync',
      gameMode: 'dama',
      turn: fresh.turn,
      boardSeed: 0,
      stateJson: fresh,
      winner: null,
      sender: mySlot,
    });
    await upsertActiveMatch({
      room_code: roomCode,
      game_mode: 'dama',
      turn: fresh.turn,
      board_seed: 0,
      state_json: fresh,
      winner: null,
    });
  };

  const handleCommitSnakesState = async (nextState: SnakesGameState) => {
    setSnakesState(nextState);

    channelRef.current?.sendBroadcast({
      type: 'match_sync',
      gameMode: 'snakes',
      turn: nextState.turn,
      boardSeed: nextState.boardSeed,
      stateJson: nextState,
      winner: nextState.winner,
      sender: mySlot,
    });

    await upsertActiveMatch({
      room_code: roomCode,
      game_mode: 'snakes',
      turn: nextState.turn,
      board_seed: nextState.boardSeed,
      state_json: nextState,
      winner: nextState.winner,
    });

    if (nextState.winner === 'p1' || nextState.winner === 'p2') {
      const updatedRoom = await recordMatchWinInDb(
        roomData,
        'snakes',
        nextState.winner,

      boardSeed: fresh.boardSeed,
      stateJson: fresh,
      winner: null,

    await upsertActiveMatch({
      room_code: roomCode,
      game_mode: 'snakes',
      turn: fresh.turn,
      board_seed: fresh.boardSeed,
      state_json: fresh,
      winner: null,

      id: `${Date.now()}-${Math.random().toString(36).slice(2, 6)}`,

    channelRef.current?.sendBroadcast({ type: 'reaction', reaction });

    if (mySlot !== 'p1') return;
    playTapPop();
    setRoomData((prev) => ({ ...prev, current_mode: newMode }));
    checkAutoOpenTutorial(newMode);
    channelRef.current?.sendBroadcast({
      type: 'mode_switch',

    updateRoomModeInDb(roomCode, newMode);

      handleResetDamaMatch();
    } else {
      handleNewSnakesSeedMatch(snakesState.twistsEnabled);

    } catch {
      // Ignore storage errors
    }

    if (newRoomCode !== roomCode) {
      setRoomCode(newRoomCode);
    }
    if (newSlot !== mySlot) {
      setMySlot(newSlot);
      channelRef.current?.updateSlot(newSlot);
    }

    setRoomData((prev) =>
      newSlot === 'p1'
        ? { ...prev, p1_avatar: newAvatar }
        : { ...prev, p2_avatar: newAvatar }
    );

    channelRef.current?.sendBroadcast({
      type: 'avatar_update',
      slot: newSlot,
      avatar: newAvatar,
    });

    await updatePlayerAvatarInDb(newRoomCode, newSlot, newAvatar);
  };

  const now = Date.now();
  const p1Online = mySlot === 'p1' || now - (onlineSeen.p1 || 0) < 16000;
  const p2Online = mySlot === 'p2' || now - (onlineSeen.p2 || 0) < 16000;

    roomData.current_mode === 'dama'
      ? roomData.p1_dama_wins
      : roomData.p1_snakes_wins;
  const p2Wins =
    roomData.current_mode === 'dama'
      ? roomData.p2_dama_wins
      : roomData.p2_snakes_wins;

    mySlot === 'p1' ? roomData.p1_avatar : roomData.p2_avatar;

    roomData.p2_avatar.name && roomData.p2_avatar.name !== p1DisplayName

      : 'Lovey 2';

  const activeTurnSlot: PlayerSlot =
    roomData.current_mode === 'dama' ? damaState.turn : snakesState.turn;

  const [turnBubbleText, setTurnBubbleText] = useState('Your turn!');

  useEffect(() => {
    if (
      roomData.current_mode === 'snakes' &&
      snakesState.lastAnimation?.eventMessage
    ) {

        setTurnBubbleText('Your turn!');
      }, 1800);
      return () => window.clearTimeout(t);
    }
    setTurnBubbleText('Your turn!');
  }, [
    roomData.current_mode,
    snakesState.lastAnimation?.id,
    snakesState.lastAnimation?.eventMessage,
  ]);

  const p1CapturedCount = Math.max(0, 12 - damaState.p2Remaining);
  const p2CapturedCount = Math.max(0, 12 - damaState.p1Remaining);

  return (
    <main className="arcade-shell">
      {activeScreen === 'menu' ? (
        <HomeMenuView
          roomData={{
            ...roomData,
            p1_avatar: { ...roomData.p1_avatar, name: p1DisplayName },
            p2_avatar: { ...roomData.p2_avatar, name: p2DisplayName },
          }}
          p2Online={p2Online}
          onOpenSettings={() => setCustomizerOpen(true)}
          onStartAsHost={handleStartAsHost}
          onAttemptJoinAsInvited={handleAttemptJoinAsInvited}
          onHostLaunchGame={handleHostLaunchGame}
        />
      ) : (
        <div className="ingame-screen-layout">
          {/* Minimal In-Game Top Bar: Top-Left Settings Button + Centered Game Sticker Pill */}
          <header className="ingame-top-bar">
            <button
              type="button"
              className="icon-circle-btn sticker-press"
              onClick={() => setCustomizerOpen(true)}
              aria-label="Open Settings"
              title="Settings"
            >
              <SettingsGearIcon size={22} />
            </button>

            <div className="ingame-title-pill">
              {roomData.current_mode === 'dama' ? (
                <>
                  <CrownIcon size={16} />
                  <span>Cat Dama</span>

              ) : (

                  <SnakeLadderIcon size={16} />

          </header>

          <div className="ingame-board-center">
            {roomData.current_mode === 'dama' ? (
              <DamaBoardView
                gameState={damaState}
                mySlot={mySlot}
                p1Avatar={{ ...roomData.p1_avatar, name: p1DisplayName }}
                p2Avatar={{ ...roomData.p2_avatar, name: p2DisplayName }}
                passAndPlay={passAndPlay}
                onCommitState={handleCommitDamaState}
                onResetMatch={handleResetDamaMatch}
              />
            ) : (
              <SnakesBoardView
                gameState={snakesState}
                mySlot={mySlot}
                p1Avatar={{ ...roomData.p1_avatar, name: p1DisplayName }}
                p2Avatar={{ ...roomData.p2_avatar, name: p2DisplayName }}
                passAndPlay={passAndPlay}
                onCommitState={handleCommitSnakesState}
                onNewSeedMatch={handleNewSnakesSeedMatch}
              />
            )}
          </div>

          {/* Bottom Dock: Centered Sticker Scoreboard Bar + Bottom-Right Chat Sheet Button */}
          <footer className="ingame-bottom-dock">
            <button
              type="button"
              className="bottom-scoreboard-bar sticker-press"
              onClick={() => setScoreboardOpen(true)}
              title="Tap to view Match Scoreboard"
            >
              {/* Player 1 Side */}
              <div
                className={`bottom-player-side ${
                  activeTurnSlot === 'p1' ? 'active-turn' : 'dim-turn'
                }`}
              >
                {activeTurnSlot === 'p1' && (
                  <span className="turn-speech-bubble">{turnBubbleText}</span>
                )}
                <div
                  className={`cat-badge mini ${
                    activeTurnSlot === 'p1' ? 'avatar-turn-bounce' : ''
                  }`}
                >
                  <CatAvatarSvg
                    breed={roomData.p1_avatar.breed}
                    accessory={roomData.p1_avatar.accessory}
                    size={28}
                    animateIdle={false}
                  />
                  <span
                    className={`online-dot ${p1Online ? 'online' : ''}`}
                  />
                </div>
                <div className="bottom-player-meta">
                  <span className="bottom-player-name">{p1DisplayName}</span>
                  <span className="bottom-turn-tag">
                    {roomData.current_mode === 'dama' ? (
                      <>
                        <PawIcon size={10} /> {p1CapturedCount} captured
                      </>
                    ) : (
                      `Tile ${snakesState.p1Tile}`
                    )}
                  </span>
                </div>
              </div>

              {/* Center Score Pill */}
              <div className="bottom-score-center">
                <TrophyIcon size={14} />
                <span className="bottom-score-digits">
                  {p1Wins} : {p2Wins}
                </span>
              </div>

              {/* Player 2 Side */}
              <div
                className={`bottom-player-side right ${
                  activeTurnSlot === 'p2' ? 'active-turn' : 'dim-turn'
                }`}
              >
                {activeTurnSlot === 'p2' && (
                  <span className="turn-speech-bubble">{turnBubbleText}</span>
                )}
                <div
                  className={`cat-badge mini ${
                    activeTurnSlot === 'p2' ? 'avatar-turn-bounce' : ''
                  }`}
                >
                  <CatAvatarSvg
                    breed={roomData.p2_avatar.breed}
                    accessory={roomData.p2_avatar.accessory}
                    size={28}
                    animateIdle={false}
                  />
                  <span
                    className={`online-dot ${p2Online ? 'online' : ''}`}
                  />
                </div>
                <div className="bottom-player-meta">
                  <span className="bottom-player-name">{p2DisplayName}</span>
                  <span className="bottom-turn-tag">
                    {roomData.current_mode === 'dama' ? (
                      <>
                        <PawIcon size={10} /> {p2CapturedCount} captured
                      </>
                    ) : (
                      `Tile ${snakesState.p2Tile}`
                    )}
                  </span>
                </div>
              </div>
            </button>

            <QuickChatBar onSendReaction={handleSendReaction} />
          </footer>
        </div>
      )}

      {/* Floating Compositor Sticker/Chat Layer */}
      <div className="floating-layer" aria-live="polite">
        {reactions.map((item) => (
          <div
            key={item.id}
            className={`floating-bubble from-${item.sender} kind-${item.kind}`}
          >
            {item.kind === 'emoji' && VALID_STICKER_IDS.has(item.content) ? (
              <ReactionStickerSvg
                id={item.content as ReactionStickerId}
                size={40}
                animated
              />
            ) : (
              item.content
            )}
          </div>
        ))}
      </div>

      {/* Unified 3-Tab Settings & Cat Customizer Modal */}
      <CatCustomizerModal
        isOpen={customizerOpen}
        isInGame={activeScreen === 'play'}
        roomCode={roomCode}
        mySlot={mySlot}
        currentMode={roomData.current_mode}
        currentAvatar={myCurrentAvatar}
        muted={muted}
        passAndPlay={passAndPlay}
        onToggleMute={handleToggleMute}
        onTogglePassAndPlay={() => setPassAndPlay((p) => !p)}
        onHostSwitchGame={handleHostSwitchMode}
        onHostResetMatch={handleHostResetCurrentMatch}
        onOpenTutorial={() => setTutorialOpen(true)}
        onExitToMenu={() => setActiveScreen('menu')}
        onSave={handleSaveLobby}
        onClose={() => setCustomizerOpen(false)}
      />

      {/* Minimalist Couple Scoreboard Modal */}
      <CoupleScoreboardModal
        isOpen={scoreboardOpen}
        roomData={roomData}
        onClose={() => setScoreboardOpen(false)}
      />

      {/* Auto First-Game & On-Demand Rules Tutorial Modal */}
      <DamaTutorialModal
        isOpen={tutorialOpen}
        gameMode={roomData.current_mode}
        onClose={() => setTutorialOpen(false)}
      />
    </main>
  );
}

-- ============================================================================
-- Cartoon Cat Couple's Arcade — Supabase PostgreSQL Schema
-- Run this entire script in your Supabase Dashboard -> SQL Editor -> New Query
-- ============================================================================

-- 1. Couple Rooms Table (Persistent room, customizable Cat Avatars, Lifetime Scoreboard)
create table if not exists public.couple_rooms (
  room_code text primary key,
  p1_avatar jsonb not null default '{"name":"Lovey 1","breed":"strawberry-cat","accessory":"crown"}'::jsonb,
  p2_avatar jsonb not null default '{"name":"Lovey 2","breed":"orange-tabby","accessory":"ribbon"}'::jsonb,
  p1_dama_wins integer not null default 0,
  p2_dama_wins integer not null default 0,
  p1_snakes_wins integer not null default 0,
  p2_snakes_wins integer not null default 0,
  current_mode text not null default 'dama' check (current_mode in ('dama', 'snakes')),
  updated_at timestamptz not null default now()
);

-- 2. Active Matches Table (Authoritative board state & boardSeed for instant reconnect)
create table if not exists public.active_matches (
  room_code text primary key references public.couple_rooms(room_code) on delete cascade,
  game_mode text not null default 'dama' check (game_mode in ('dama', 'snakes')),
  turn text not null default 'p1' check (turn in ('p1', 'p2')),
  board_seed integer not null default 123456,
  state_json jsonb not null default '{}'::jsonb,
  winner text check (winner in ('p1', 'p2', 'draw') or winner is null),
  updated_at timestamptz not null default now()
);

-- 3. Match History Table (Recent couple match log)
create table if not exists public.match_history (
  id uuid primary key default gen_random_uuid(),
  room_code text not null references public.couple_rooms(room_code) on delete cascade,
  game_mode text not null check (game_mode in ('dama', 'snakes')),
  winner text not null check (winner in ('p1', 'p2', 'draw')),
  p1_name text not null,
  p2_name text not null,
  summary text not null default '',
  played_at timestamptz not null default now()
);

-- 4. Enable Row Level Security (Open anonymous access scoped by room_code for frictionless 2-player couple login)
alter table public.couple_rooms enable row level security;
alter table public.active_matches enable row level security;
alter table public.match_history enable row level security;

drop policy if exists "Allow anon access to couple_rooms" on public.couple_rooms;
create policy "Allow anon access to couple_rooms"
  on public.couple_rooms for all
  using (true)
  with check (true);

drop policy if exists "Allow anon access to active_matches" on public.active_matches;
create policy "Allow anon access to active_matches"
  on public.active_matches for all
  using (true)
  with check (true);

drop policy if exists "Allow anon access to match_history" on public.match_history;
create policy "Allow anon access to match_history"
  on public.match_history for all
  using (true)
  with check (true);

-- 5. Enable Realtime Postgres Changes for couple_rooms and active_matches
alter publication supabase_realtime add table public.couple_rooms;
alter publication supabase_realtime add table public.active_matches;

# Cartoon Cat Couple's Arcade — Project Optimization & Architecture Rules

## 1. Target Hardware & Viewport Constraints

Every component, stylesheet, and game engine module MUST strictly support our dual-device baseline:

1. **Samsung Galaxy J2 Pro (Strict Baseline Constraint)**
   - **Viewport:** `360 × 640 px` CSS (`540 × 960` physical, 16:9, 60 Hz).
   - **Hardware:** `1.5 GB – 2 GB` RAM, Quad-core Cortex-A53 + Adreno 308 GPU.
   - **Hard Budgets:**
     - **Gzipped JS Bundle:** `< 45 KB` total (use lightweight Preact + modular Supabase usage; zero bloated UI or animation libraries).
     - **DOM Node Count:** `< 400` total nodes on screen at any time.
     - **Memory Footprint:** `< 50 MB` heap/raster memory (no large PNG/WebP sprite sheets, no WebGL/Canvas2D framebuffers).
     - **Zero Scrollbars:** Entire app fits inside `100dvh` (`overflow: hidden`) with a responsive square SVG board container (`min(100vw - 16px, 100dvh - 188px)`).

2. **Poco X7 Pro (High-Refresh Modern Target)**
   - **Viewport:** `393 × 873 px` CSS (`1220 × 2712` physical, 20:9 AMOLED, 120 Hz).
   - **Safe-Area Insets:** Respect `env(safe-area-inset-top)` and `env(safe-area-inset-bottom)` for punch-hole camera and gesture navigation bar.
   - **High-DPI Vector Crispness:** All game boards, cat avatars, pieces, snakes, and ladders must be rendered as scalable inline `<svg>` vectors so they run at locked 120 FPS at native resolution.

---

## 2. Graphics & GPU Compositor Animation Rules

- **Compositor-Only Animations:** Animate ONLY `transform` (`translate3d`, `scale`, `rotate`) and `opacity`.
- **Forbidden CSS Properties on Animated Elements:** NEVER animate `top`, `left`, `width`, `height`, `margin`, `box-shadow`, or `filter`.
- **Forbidden Expensive Paint Effects:** NEVER use `backdrop-filter: blur()`, heavy multi-layered `drop-shadow` filters on moving nodes, or continuous CSS `infinite` animations on more than 4 elements simultaneously.
- **Touch Ergonomics:**
  - All interactive board tiles, cat pieces, dice boxes, and emoji triggers MUST maintain a minimum hit target of `42 × 42 px` (or equivalent SVG coordinate hit area).
  - Use **Tap-to-Select, Tap-to-Move** interaction (never drag-and-drop, which drops frames and misfires on small capacitive screens).
  - Apply `touch-action: manipulation` and `-webkit-tap-highlight-color: transparent` globally.

---

## 3. Architecture & Code Quality Guidelines

- **Pure Deterministic Game Engines:**
  - `src/engines/damaEngine.ts` (Filipino Dama) and `src/engines/snakesEngine.ts` (Seeded Snakes & Ladders) must be 100% pure TypeScript functions with zero DOM or Preact dependencies.
  - All random board generation in Snakes & Ladders must use the deterministic `Mulberry32` PRNG seeded by `boardSeed` so both phones generate identical boards with `0 KB` extra network payload.
- **Network Resilience:**
  - Ephemeral visual events (floating emoji reactions, quick chat bubbles, dice shake preview) use **Supabase Realtime Broadcast** (`< 50 ms`).
  - Authoritative turn states and match outcomes persist to **Supabase PostgreSQL** (`couple_rooms`, `active_matches`, `match_history`) so locking a phone or dropping mobile data recovers seamlessly on wake.
- **Verification & Git Checkpoints:**
  - Before every commit/checkpoint, run `npx.cmd tsc --noEmit` and `npm.cmd run build` to verify zero TypeScript errors and confirm the gzipped bundle stays `< 45 KB`.

# Cartoon Cat Couple's Arcade 🐾👑🐍

A lightweight, real-time multiplayer couple's web game hub built for long-distance play—featuring **Traditional Filipino Dama** and **Seeded Randomized Snakes & Ladders**, customizable **Cartoon Cat Avatars** (8 breeds + accessories), 60/120 FPS GPU-compositor animations, floating emoji/chat bubbles, synthesized Web Audio SFX, and persistent Supabase scoreboards.

## Target Devices & Performance
- **Samsung Galaxy J2 Pro (`360 × 640 px` CSS, 60 Hz):** `< 22 KB` gzipped JS bundle (`< 45 KB` budget), zero scrollbars (`100dvh`), `>= 42 × 42 px` touch targets.
- **Poco X7 Pro (`393 × 873 px` CSS, 120 Hz):** `env(safe-area-inset-top/bottom)` support and razor-sharp inline `<svg>` vector rendering at 120 FPS.

## Features
1. **8 Cartoon Cat Breeds + 5 Accessories:** Strawberry Cat, Orange Tabby, Calico, Tuxedo, Siamese, Void Black Cat, Scottish Fold, and White Persian + Crown (`👑`), Ribbon (`🎀`), Sakura (`🌸`), and Shades (`🕶️`).
2. **Traditional Filipino Dama (`src/engines/damaEngine.ts`):**
   - `8×8` diagonal-line board, forward/backward *Tao* captures, flying *Dama* kings (with crown & cape), mandatory maximum capture (*Mayor*) highlighting, and **Cat Pounce + Paw Smack Cloud Poof** capture animations.
3. **Seeded Randomized Snakes & Ladders (`src/engines/snakesEngine.ts`):**
   - `Mulberry32` deterministic PRNG synced via `boardSeed` in Supabase.
   - Procedural wooden ladders, colorful cartoon snakes, and optional Mystery Twist tiles (`⚡ Boost +3`, `🛡️ Snake Shield`, `🎲 Extra Roll`, `🔄 Switcheroo Swap`).
   - Cat Paw Dice Box roll, `boing-boing` tile hopping, and dizzy spiral eyes (`@_@`) on snake slides.
4. **Couple Realtime Sync & Lifetime Scoreboard:**
   - `< 50ms` Supabase Realtime Broadcast for floating emojis (`😻`, `😹`, `😿`, `🐾`, `🐟`, `❤️`) and quick chat notes.
   - PostgreSQL persistence (`couple_rooms`, `active_matches`, `match_history`) for instant wake/reconnect recovery.
